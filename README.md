## How to Compile and Run
Install a C++ compiler such as GCC and open a terminal in the repository folder.

Compile a program:

```bash
g++ prac1.cpp -o prac1
```

Run on Windows:

```powershell
.\prac1.exe
```

Replace `prac1.cpp` with the filename of the program you want to execute.
